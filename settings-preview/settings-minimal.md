# Settings Page - Minimalist Redesign

## Design Direction
- Platform: iOS-native premium minimal
- Style: Flat, no gradients, no decorative elements
- Colors: 
  - Background: #FFFFFF (pure white)
  - Text Primary: #1C1C1E (near black)
  - Text Secondary: #8E8E93 (gray)
  - Dividers: #E5E5EA
  - Accent: #007AFF (iOS blue)
  - Status OK: #34C759
  - Status Warning: #FF9500

## Typography
- Title: SF Pro Display Bold 28px
- Section Header: SF Pro Text Semibold 13px uppercase, #8E8E93
- Row Label: SF Pro Text Regular 17px
- Row Value: SF Pro Text Regular 17px
- Caption: SF Pro Text Regular 13px

## Layout
- Safe area padding: 16px horizontal
- Section spacing: 32px vertical
- Row height: 44px
- Row divider: 0.5px #E5E5EA, 16px left inset
- Corner radius: 0 (flat rectangles)

## Structure

### Header
- Back button: Simple chevron left icon
- Title: "Settings" centered

### Section 1: Version
- Row: App icon (simple flat) | Version number | Update button (flat blue)
- Simple, one row

### Section 2: Connection
- Row: Globe icon | Connection status text
- Simple status indicator

### Section 3: Server Config (Read-only)
- Row: Lock icon | Server URL | Read-only badge
- Dimmed, non-interactive appearance

### Footer
- App name and offline indicator
- Minimal, understated

## No gradients, no cards, no shadows, no decorative elements
