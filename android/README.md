# Trip Angkutan Android

Native Android wrapper for the Trip Angkutan mobile application. The user interface and business logic are implemented with HTML and TypeScript in the parent project; this directory contains the Capacitor Android shell, native configuration, and Gradle build setup.

## Features

- PIN-based login and session restoration
- Home dashboard with trip and vehicle summaries
- Online/offline status and manual synchronization
- Trip creation with load status and condition photo capture
- Vehicle entry with plate number, category, vehicle type, load status, selfie, and GPS location
- Trip history and detail views with totals in IDR
- Profile and logout flow
- Offline-first local persistence with automatic and manual sync
- Capacitor integrations for camera, geolocation, network status, preferences, haptics, keyboard, app lifecycle, and status bar

## Technology

- Android Gradle Plugin `8.13.0`
- Gradle `8.14.3`
- Java `21`
- Android `minSdkVersion 24`, `compileSdkVersion 36`, `targetSdkVersion 36`
- Capacitor Android `7.6.9`
- HTML and TypeScript
- AndroidX, JUnit, and Espresso

The Android source is a thin native host. `MainActivity` extends Capacitor's `BridgeActivity`; the application screens and services live in `../src`.

## Prerequisites

- Android Studio or a compatible Android SDK installation
- JDK 21
- Android SDK API 36
- Node.js and npm for building the HTML/TypeScript web app
- An Android device or emulator for installation and instrumentation tests

## Development workflow

Run these commands from the repository root to rebuild the web app and synchronize it into Android:

```bash
npm install
npm run build
npx cap sync android
```

Then build the Android debug APK from this directory:

```bash
cd android
./gradlew assembleDebug
```

On Windows:

```powershell
cd android
.\gradlew.bat assembleDebug
```

The debug APK is written to:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Running and debugging

Open the `android` directory in Android Studio, select the `app` module, and run it on a connected device or emulator.

From the command line, install the debug build with:

```bash
./gradlew installDebug
```

## Tests

Run the local JVM tests:

```bash
./gradlew test
```

Run instrumentation tests with a connected Android device or emulator:

```bash
./gradlew connectedAndroidTest
```

The web application's tests and lint checks are run from the repository root with:

```bash
npm test
npm run lint
```

## Configuration

- The canonical Capacitor configuration is `../capacitor.config.ts`.
- The Android application ID is `com.plantation.tripangkut`.
- The app name is `Trip Angkutan`.
- The API base URL is configured in `../src/environments/environment.ts` and `environment.prod.ts`.
- SDK versions and dependency versions are centralized in `variables.gradle`.
- The generated files under `app/src/main/assets` and `app/src/main/res/xml/config.xml` should be refreshed with `npx cap sync android` rather than edited directly.

## Backend integration

The app communicates with the configured REST API for login, token refresh, trip and vehicle creation, trip completion, and photo uploads. The current environment configuration uses `https://api.tripangkut.com/v1`.

Firebase/Google Services are optional. The Gradle script applies the Google Services plugin only when `app/google-services.json` is present; push notifications will not work without the appropriate backend configuration.

## Release builds

The project currently has no signing configuration. Configure a release keystore and signing properties in `app/build.gradle` or through the Android Studio signing workflow before producing a signed release APK or AAB. Keep keystore files and credentials out of version control.
