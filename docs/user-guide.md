# Cara Menggunakan Aplikasi Trip

## Aplikasi Trip

### Daftar Fitur
- **Login dan Registrasi**
  - Kunjungi halaman login atau registrasi pada aplikasi.
  - Isi formulir dengan data yang diperlukan, termasuk nama, email, dan password.
  - Tekan tombol 'Login' untuk masuk atau 'Daftar' untuk mendaftar akun baru.
- **Pemesanan Angkutan**
  - Pilih tujuan dan waktu pemberangkatan.
  - Pilih provider angkutan yang tersedia, termasuk angkutan kota dan taksi.
  - Isi detail pemesanan, seperti jumlah penumpang, jenis tiket (ekonomi atau premium).
  - Konfirmasi pesanan dan bayar melalui metode pembayaran yang tersedia (Transfer Bank, OVO, Dana, Gopay).
- **Lacak Status Pemesanan**
  - Masuk ke menu 'Lacak Pemesanan' di aplikasi.
  - Masukkan kode pemesanan atau nomor pesanan.
  - Aplikasi akan menampilkan status pemesanan, termasuk informasi tentang jadwal dan driver.
- **Notifikasi**
  - Aplikasi akan mengirim notifikasi melalui push notification atau email kepada user tentang status pemesanan dan promosi.

## Website Admin Dashboard

### Daftar Fitur
- **Dashboard Utama**
  - Menampilkan statistik penting seperti jumlah user, transaksi, dan laporan.
  - Menampilkan grafik keuntungan harian, mingguan, dan bulanan.
  - Menampilkan laporan transaksi dan penjualan.
- **Pengelolaan User**
  - Menambah, mengedit, dan menghapus user.
  - Mengatur hak akses dan role user.
  - Memblokir atau menonaktifkan user jika diperlukan.
- **Pengelolaan Angkutan**
  - Menambah, mengedit, dan menghapus provider angkutan.
  - Mengatur harga tiket dan layanan tambahan (wifi, AC, dll).
  - Menampilkan statistik penggunaan angkutan.
- **Laporan Transaksi**
  - Melihat detail transaksi user.
  - Mengelola laporan penjualan harian, mingguan, dan bulanan.
  - Menyusun laporan keuangan secara real-time.

### Panduan Pengguna Admin
1. **Login**
   - Kunjungi halaman login admin.
   - Masukkan username dan password.
   - Tekan tombol 'Login' untuk masuk.
2. **Dashboard Utama**
   - Setelah login, Anda akan diarahkan ke dashboard utama.
   - Di sini Anda dapat melihat statistik penting seperti jumlah user, transaksi, dan laporan.
3. **Pengelolaan User**
   - Klik menu 'Pengelolaan User'.
   - Anda dapat menambah, mengedit, atau menghapus user.
   - Mengatur hak akses dan role user.
   - Memblokir atau menonaktifkan user jika diperlukan.
4. **Pengelolaan Angkutan**
   - Klik menu 'Pengelolaan Angkutan'.
   - Anda dapat menambah, mengedit, atau menghapus provider angkutan.
   - Mengatur harga tiket dan layanan tambahan (wifi, AC, dll).
   - Menampilkan statistik penggunaan angkutan.
5. **Laporan Transaksi**
   - Klik menu 'Laporan Transaksi'.
   - Anda dapat melihat detail transaksi user.
   - Mengelola laporan penjualan harian, mingguan, dan bulanan.
   - Menyusun laporan keuangan secara real-time.

## Kesimpulan

Aplikasi Trip dan website admin dashboard dirancang untuk memberikan pengalaman yang mudah dan efisien bagi user dan admin. Dengan fitur-fitur lengkap, kedua platform ini dapat membantu meningkatkan layanan angkutan kota dan manajemen operasional.
